# Meow Cosmetics

Client-side cosmetics for Minecraft 26.1.2 (Fabric). Only you see them, on your own player; nothing is sent to any server.

- Animated capes (Starry Forest, Sakura, Aurora) or your own cape images (`config/meowcosmetics/capes`)
- Cat ears and a cat tail, with colours and fit settings
- Auras: bats, hearts, sparkles, cats
- Pets: 7 cat coats and 6 slimes, by your left or right shoulder
- Hide Armor (with a key)

Open the settings with `/cosmetics`, or set a key under **Controls → Meow Cosmetics**.

## Building

```
./gradlew build
```
The jar ends up in `build/libs/`. Needs Java 21+, Fabric Loader and Fabric API.
